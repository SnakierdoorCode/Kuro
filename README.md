# Kuro
**Kuro** is translated to black in japanese, all original credit goes towards nautilus-os for letting this project be possible.


__Kuro__ is a proxy branched off of the nautilus-os proxy named GUST, which has been modified to be changed towards the name called Kuro, note that this isn't a direct spin-off with zero credit to the official owners, all credits goes towards the team that built the backend/main chunk of nautilus-os, this is merely just a spin-off with different css and likings towards the name Kuro, which translated means black in japanese
